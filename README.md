# Contact App 📱

A simple and user-friendly Flutter application for managing contacts.

## 🎥 App Demo

https://github.com/user-attachments/assets/103504bb-f7e7-4b7d-b4c4-73d933b25f10

## ✨ Features

- Add new contacts.
- Display contacts in a grid layout.
- Edit contact information.
- Update contact profile pictures.
- Delete individual contacts.
- Pick profile pictures from the device gallery.

## 🛠️ Built With

- Flutter
- Dart
- Image Picker
- Lottie

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/DoaaAbdallah1/contact_app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd contact_app
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
